# Bio-computation projects

Coursework implementations for computational biology.

## Projects

- [`project1/`](project1/): protein secondary structure prediction, including preprocessing, a CNN baseline, dilated CNN and BiLSTM candidates, evaluation, and submission packaging.

The current Project 1 implementation has received static checks only. Data reconstruction, training, prediction, evaluation, and runtime testing have not been executed; no measured model results or trained weights are included.

Course data and the assignment PDF must be provided separately. Place the supplied `source_data/` and `standard_data/` under `project1/` before following its documentation. Data, generated results, environments, credentials, and weights are intentionally excluded from this repository.
